# ADR 0008：刻み幅は埋め込みルンゲ＝クッタ法で制御し，長時間の計算にはシンプレクティック法を使う

## 状況

一定の刻み幅で解くと，解が速く変わる区間に合わせて刻み幅を決めることになり，ほかの区間では無駄なステップが増える．
局所誤差を推定できれば，必要な精度に合わせて刻み幅を変えられる．
一方，惑星の運動のように長い時間を解く計算では，誤差の大きさより保存量(エネルギー，角運動量)の振る舞いが問題になる．
RK4のような方法は，1周期の誤差は小さくても，エネルギーの誤差が時間に比例してたまる．

## 決定

- 刻み幅の制御には，Bogacki–Shampineの3(2)次の組を使う．3次の解と2次の解の差を局所誤差の推定にし，3次の解を受理する(局所外挿)．
- 誤差の尺度は，各成分の目標atol + rtol·max(|yᵢ|, |y_newᵢ|)で推定を割った値の2乗の平均の平方根errとする．err ≤ 1なら受理する．
- 次の刻み幅は，hに0.9·err^(−1/3)を掛けて求め，掛ける値を1/5以上5以下に制限する．
- ハミルトン系の長時間の計算には，Störmer–Verlet法を使う．
- テストでは，`integrate_adaptive`の大域誤差の上界を主張しない．保存量の検査は，丸め誤差の上界を導いてから行う．

ほかの候補と比べた結果は次のとおりである．

- 刻み幅を2つ(hとh/2)で解いて差から推定する：推定のための計算が埋め込み法の約3倍になる．
- Dormand–Princeの5(4)次の組：効率は良いが係数が多く，このコースで係数を確かめるテストを書く手間が大きい．方法の考え方は同じである．
- FSAL(最後の段の傾きを次のステップの最初の段に使う)：右辺の評価を1回減らせるが，受理と棄却で状態を持ち回る必要があり，コードが複雑になる．使わない．
- 長時間の計算にRK4を使い，刻み幅を小さくする：エネルギーの誤差は小さくなるが，たまることは変わらない．

## 結果

- 刻み幅は解の変化に合わせて変わり，許容誤差tolを1/10にすると，ステップ数は約10^(1/3)倍になる．
- 大域誤差はtolにほぼ比例するが，tol以下とは限らない．利用者には，tolは局所誤差の目標であることを説明する必要がある．
- Störmer–Verlet法は2次の方法で，1ステップの精度はRK4より低い．代わりに，エネルギーの誤差は有界にとどまり，中心力の角運動量は丸め誤差の分しか変わらない．

## 検証

- `bs32_step`の3次の解の大域誤差と1ステップの推定の観測次数を，ADR 0007の基準で検査する．
- tolを1/10ずつ小さくしたとき，大域誤差が単調に減り，ステップ数が単調に増えることを検査する．
- 有理数で計算し，修正エネルギーと角運動量が厳密に保たれること，時間を反転すると元に戻ることを`==`で検査する．
- `Float64`で10⁶ステップ解き，保存量の変化が丸め誤差の上界以下であることを検査する．
- ケプラー問題で，エネルギーの誤差が時間とともにたまらないことを検査する．
