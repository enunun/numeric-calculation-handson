# ADR 0003：分散をWelfordの算法で求める

## 状況

教科書の公式(Σxᵢ² − (Σxᵢ)²/n)/(n − 1)は，データを1回走査するだけで分散を求められる．
しかし，平均が標準偏差に比べて大きいとΣxᵢ²と(Σxᵢ)²/nはほぼ等しくなり，引き算で桁落ちが起きる．
相対誤差は分散の条件数κ_vの2乗に比例し，`[1e9 + 4, 1e9 + 7, 1e9 + 13, 1e9 + 16]`では，正しい分散30.0に対して−170.66666666666666を返す．

## 決定

`variance`には，Welfordの算法を使う．
データを1回走査しながら，平均mと偏差平方和Sを次のように更新する．

```text
d = xₖ − m,   m ← m + d/k,   S ← S + d(xₖ − m)
```

ほかの候補と比べた結果は次のとおりである．

- 教科書の公式：1回の走査で済むが，相対誤差がκ_v²に比例し，負の分散を返すことがある．比較のため`textbook_variance`として残す．
- 2回走査する方法(先に平均を求め，次にΣ(xᵢ − x̄)²を求める)：精度はよい(一次の誤差はnu程度)が，データを2回読む必要がある．
- 有理数や`BigFloat`による計算：正確だが遅い(条件数の計算`variance_condition_number`とテストの参照解には使う)．

## 結果

- 相対誤差は一次の見積もりでnκ_v·u程度になり，κ_vに比例する(2乗ではない)．
- 結果は負にならず，定数のデータでは厳密に0を返す．
- データを1回走査するだけで済むので，データを順に受け取る場面(ストリーム)にも使える．
- 1要素あたりの演算は，教科書の公式より多い(割り算が1回加わる)．

## 検証

- 乱数で作った条件数1〜10⁸のデータで，相対誤差がγ₂ₙ·κ_v以下であることを，有理数で求めた参照解と比べて検査する．
- 負にならないこと，定数のデータで0になること，2の冪による拡大縮小で厳密に4ᵏ倍になることを，`==`と`>=`で検査する．
- 平行移動と並べ替えで結果が許容誤差の範囲でしか変わらないことを，参照解を使わずに検査する．
