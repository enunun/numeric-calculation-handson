# ADR 0006：指数関数は引数還元と13次のテイラー多項式で計算し，誤差予算で上界を示す

## 状況

exp(x)をテイラー級数でそのまま計算すると，|x|が大きいとき多くの項が要り，x < 0では大きな項どうしの打ち消しで桁落ちする．
また，`Float64`の結果を「誤差1 ULP未満」と主張するには，各段の誤差を積み上げた根拠が要る．
実測で誤差が小さくても，それだけでは保証にならない．

## 決定

- 引数をx = k·ln 2 + r，k = round(x/ln 2)，|r| ≤ ln 2/2と還元し，exp(x) = 2ᵏ·exp(r)で計算する．
- ln 2をLN2_HI + LN2_LOに分割し(Cody–Waiteの方法)，r = (x − k·LN2_HI) − k·LN2_LOとする．LN2_HIの仮数の下位21ビットは0なので，k·LN2_HIは丸めずに計算でき，x − k·LN2_HIも厳密になる．
- exp(r)は1 + s，s = r + r²Q(r)で求める．Q(r)(rʲを(j + 2)の階乗で割った項をj = 0から11まで足した多項式)はHorner法で評価する．全体は13次のテイラー多項式である．
- 誤差の主張は誤差予算で導いた上界とし，正規化数の結果で1.3 ULP，非正規化数の結果で1.8 ULPとする．

次数は，打ち切り誤差を評価の丸め誤差より十分小さくする最小の次数を選んだ．
|r| ≤ ln 2/2で，13次の剰余は約0.05 ULP，12次では数ULPになる．

ほかの候補と比べた結果は次のとおりである．

- 還元に`x - k * log(2.0)`を使う：k·log(2.0)の積の丸めと，ln 2の丸め誤差のk倍がrに入る．x = 693，k = 1000ではrの誤差が約6.8 × 10⁻¹⁴になり，結果の誤差は数百ULPになる．
- ミニマックス多項式(Remezの方法)：同じ精度をより低い次数で達成できるが，係数の求め方の説明が別に要る．
- 表を使う方法(exp(j/2ᵐ)の表と組み合わせる)：正しい丸めに近い精度が得られるが，表の正しさの検証が別に要る．

## 結果

- 結果は1.3 ULP以内(正規化数)で，1 ULP未満は保証しない．実測の最大値は0.93 ULPである．
- 誤差予算が1 ULPを超えるので，単調性は保証されない．
- 非正規化数の結果では，`ldexp`の2回目の丸めで上界が1.8 ULPになる．

## 検証

- 全範囲からの乱数の標本と0の近くの標本で，ULP誤差が上界以下であることを`BigFloat`の参照解と比べて検査する．
- オーバーフローとアンダーフローの境界，還元の切り替わり(±ln 2/2)，0の近くの値で検査する．
- 誤差が大きくなりやすい4つの点の前後1万個ずつの連続する浮動小数点数を，すべて検査する(局所的な全数検査)．
- exp(x)·exp(−x) = 1の性質と，`Base.exp`との差分テストで，参照解を使わずに検査する．
