# 誤差仕様書

公開する関数ごとに，解く問題の条件数，アルゴリズムの誤差界，テストで使う許容誤差とその根拠，検証するテストを示す．
uは単位丸め(`Float64`では2⁻⁵³)，γₙ = nu/(1 − nu)である．
κ = Σ|xᵢ|/|Σxᵢ|は総和の条件数を表す．
二次方程式p(x) = ax² + bx + cの根rについて，S(r) = |a|r² + |b||r| + |c|とし，次の2つを使う．

- 根の後退誤差η(r) = |p(r)|/S(r)：rを厳密な根とするように係数を相対的に変えるときの，変える量の最小値．
- 根の条件数κ_r = S(r)/|r·p′(r)|：係数の相対的な変化を，根の相対的な変化では何倍に拡大するか．

判別式の条件数をκ_d = (b² + 4|ac|)/|b² − 4ac|とする．

データx₁, …, xₙの偏差平方和をS = Σ(xᵢ − x̄)²とし，分散の条件数をκ_v = ‖x‖₂/√Sとする．
各xᵢを相対ε以下だけ変えたとき，Sの相対的な変化は一次の近似で2κ_v·ε以下である．

n × n行列Aについて，‖·‖は∞ノルム，κ(A) = ‖A‖∞‖A⁻¹‖∞とする．
計算したLU分解をL̂，Ûとし，M = |L̂||Û|(要素ごとに絶対値をとった行列の積)，R = |PA − L̂Û|，ω = ‖M‖∞/‖A‖∞とする．増大因子をρ = maxᵢⱼ|ûᵢⱼ|/maxᵢⱼ|aᵢⱼ|とすると，部分ピボット選択では|l̂ᵢⱼ| ≤ 1なのでω ≤ n²ρである．
解x̂の後退誤差はη = ‖b − Ax̂‖/(‖A‖·‖x̂‖ + ‖b‖)である(Rigal–Gaches)．

三角行列Tの連立1次方程式の解x̂について，成分ごとの後退誤差をω_c = maxᵢ|b − Tx̂|ᵢ/(|T||x̂|)ᵢとする(Oettli–Prager)．

m × n行列A(m ≥ n)の最小二乗問題min‖Ax − b‖₂では，‖·‖₂は2ノルム，κ₂(A) = σ_max/σ_minは2ノルムの条件数(`cond`で計算)とする．
最小二乗解をx，残差をr = b − Axとし，ρ = ‖r‖₂/(‖A‖₂‖x‖₂)とする．

## 前提

- 丸めは最近接偶数丸めで，オーバーフローは起きないとする．積の無誤差変換と二次方程式では，アンダーフローも起きないとする．
- 丸め誤差の標準モデルfl(a ∘ b) = (a ∘ b)(1 + δ)，|δ| ≤ uを使う．平方根も同じモデルに従う．
- 誤差界の中のκは，テストでは有理数で厳密に求めた値(`exact_condition_number`)を使う．
- 二次方程式の参照解は，判別式を有理数で厳密に求め，256ビットの`BigFloat`で根の公式から計算する．

## quadratic_rootsの誤差界の導き方

絶対値の大きい根をr₁ = q/a，小さい根をr₂ = c/qで求める．q = −(b + sign(b)√d)/2である．

1. 判別式d̂の誤差は2 ulp以内である．1 ulpは相対2u以下なので，d̂の相対誤差は4u以下である．
2. √d̂の相対誤差は，dの誤差の半分(2u)と平方根の丸め(u)を合わせて3u以下である．
3. bとsign(b)√d̂は同符号なので，和で桁落ちは起きない．和の相対誤差は3u + u = 4u以下である．2で割るのは厳密である．
4. q/aとc/qの割り算でuずつ加わり，各根の相対誤差は5u以下になる．

二次の項を含めた上界として，テストではγ₆を使う．
判別式を素朴にb² − 4acと計算すると，2の段階でdの相対誤差が条件数に比例して大きくなり，この上界は成り立たない．

後退誤差は，根の相対誤差εから導く．r̂ = r(1 + ε)のとき，p(r̂) = r·ε·p′(r) + a·r²·ε²で，|r·p′(r)| ≤ 2S(r)なので，η ≤ 2ε + ε² ≤ γ₁₂である．

## varianceとtextbook_varianceの誤差界の導き方

教科書の公式は，Q = Σxᵢ²とT = Σxᵢを素朴に足し，S = Q − T²/nを求める．

1. Qは非負の数の和なので，相対誤差はγₙ以下である．
2. Tの絶対誤差はγₙ₋₁Σ|xᵢ|以下である．コーシー・シュワルツの不等式から|T|Σ|xᵢ|/n ≤ (Σ|xᵢ|)²/n ≤ Qなので，T²/nの絶対誤差は(2γₙ₋₁ + 2u)Q以下である(一次の近似)．
3. 引き算とn − 1での割り算の丸めで2uが加わる．

Q = κ_v²·Sなので，Sの相対誤差は一次の近似で(n + 2(n − 1) + 2)u·κ_v² + 2u ≤ (3n + 1)u·κ_v² + 2uである．
テストでは，二次の項の分として，uの係数をγで置き換えたγ₃ₙ₊₁·κ_v² + γ₂を使う．

Welfordの算法については，Chan，Golub，LeVequeが一次の近似で相対誤差をnκ_v·u程度と見積もった．
主な誤差は，平均の計算の丸め誤差がkステップ目までにk·u·|x̄|程度たまり，それが偏差平方和の増分に掛かることから生じる．
この見積もりは厳密な上界ではないので，テストでは2倍の余裕を持たせたγ₂ₙ·κ_vを使う．
条件数が1から10⁸までの3000組のデータで測った相対誤差は，最大で0.75nκ_v·uだった．

Welfordの算法には，誤差の大きさによらず厳密に成り立つ性質がある．

- 結果は負にならない．k ≥ 2のとき，更新後の平均mₖはxₖを越えないので，d = xₖ − mₖ₋₁とxₖ − mₖは同じ符号を持ち，増分d(xₖ − mₖ)は0以上である．
- 定数のデータの分散は厳密に0である．平均はデータの値から動かず，増分はすべて0である．
- データを2ᵏ倍すると，すべての中間結果が2ᵏ倍(偏差平方和は4ᵏ倍)になり，丸め誤差の相対的な大きさも変わらない．オーバーフローとアンダーフローが起きなければ，結果は厳密に4ᵏ倍になる．

## lu_factorizeとsolveの誤差界の導き方

Wilkinsonの解析(Higham，定理9.3，9.4)による．

1. ガウスの消去法で計算したL̂，Ûは，PA + ΔA = L̂Û，|ΔA| ≤ γₙ|L̂||Û|を満たす．各要素は高々n回の積和で計算されるからである．
2. 前進代入と後退代入を合わせると，計算した解x̂は(A + ΔA)x̂ = b，|ΔA| ≤ γ₃ₙPᵀ|L̂||Û|を満たす．
3. ∞ノルムをとると‖ΔA‖ ≤ γ₃ₙω‖A‖なので，Rigal–Gachesの後退誤差はη ≤ γ₃ₙωである．
4. 部分ピボット選択では|l̂ᵢⱼ| ≤ 1なので，|L̂||Û|の各要素はn·maxᵢⱼ|ûᵢⱼ|以下で，ω ≤ n²ρである．

ωとρは分解の結果から計算できる事後の量である．
ρは部分ピボット選択でも最悪2ⁿ⁻¹になりうる(Wilkinsonの例)が，実際の行列ではほとんどの場合小さい．
ピボット選択なしでは，ρはいくらでも大きくなる．

前進誤差の上界は，摂動の理論による．(A + ΔA)x̂ = b + Δbで‖ΔA‖ ≤ η‖A‖と‖Δb‖ ≤ η‖b‖が成り立ち，κ(A)η < 1とする．このとき‖x̂ − x‖/‖x‖ ≤ 2κ(A)η/(1 − κ(A)η)である．

`backward_error`は残差を有理数で厳密に計算する．
残差を浮動小数点数で計算すると，残差そのものに約γₙ₊₁(‖A‖·‖x̂‖ + ‖b‖)の誤差が入り，後退誤差を小さく見積もることがある．
その場合，前進誤差の上界2κη/(1 − κη)が成り立たなくなる．

## 最小二乗法の誤差界の導き方

ハウスホルダー変換によるQR分解は後退安定である(Higham，定理19.4，20.3)．
計算した解x̂は，A，bを列ごとに相対γ̃ₘₙ以下だけ変えた問題の厳密な最小二乗解である．
γ̃ₘₙ = c·mn·u/(1 − c·mn·u)のcは小さな定数で，値は示されていない．
最小二乗問題の摂動論(Wedin)から，前進誤差は一次の近似でγ̃ₘₙ(κ₂ + κ₂²ρ)程度になる．
ρの大きい問題(残差の大きい問題)では，前進誤差はκ₂²に比例する．

正規方程式では，AᵀAを作るときに条件数が2乗され(κ₂(AᵀA) = κ₂(A)²)，残差の大きさによらず前進誤差がκ₂²u程度になる．

定数cが示されていないので，テストではc = 1とした一次の見積もりに2倍の余裕を持たせ，γ₂ₘₙを使う．
乱数の行列(条件数1〜10¹⁰)と製造解の140組で測った値は，見積もりmn·u(κ₂ + κ₂²ρ)などに対して最大で0.64倍(直交性)だった．
κ₂は`cond`(特異値分解)で計算する．その相対誤差はκ₂u程度で，見積もりの余裕に比べて小さい．

## 許容誤差の決め方

- 誤差界が厳密な不等式で示されているときは，誤差界をそのまま許容誤差にする．
- 誤差が積み重なる計算では，各段の相対誤差を(1 + ε₁)(1 + ε₂)⋯の形で掛け合わせて上界を作る．
- 結合テストでは，計算した条件数κ̂を使う．κ̂の相対誤差は約10⁻¹³以下で，γₙ₋₁の代わりにγₙを使うことで生まれる余裕(相対1/n程度)に収まる．
- 解と係数の関係は，参照解を使わずに検査する．各根の相対誤差をγ₆以下とすると，|r̂₁ + r̂₂ + b/a| ≤ (γ₆/(1 − γ₆))(|r̂₁| + |r̂₂|)，|r̂₁r̂₂ − c/a| ≤ γ₁₂|c/a|が成り立つ．左辺は`BigFloat`で計算する．
- 参照解の精度は，256ビットと512ビットで計算した値の相対差がu²以下であることで確かめる．参照解の誤差が許容誤差より十分小さくなければ，テストは実装の誤差を測れない．
- 誤差界の式は，1との足し算が現れない形に変形してから計算する．例えば(1 + β)(1 + u) − 1を浮動小数点数で計算すると，1 + uが1に丸められて0になるので，β + u + βuと計算する．
- メタモルフィック関係の検査では，2つの計算結果がどちらも正しい値から許容誤差以内にあるので，2つの差は許容誤差の和で抑える．平行移動の検査では，平行移動そのものが厳密になるように，整数値のデータに2の冪を足す．
- 誤差界が一次の見積もりしかないとき(Welfordの算法，QR分解)は，見積もりに余裕を持たせた値を許容誤差にし，その旨と実測の値をこの文書に書く．
- 最小二乗法の参照解は2つの方法で用意する．製造解(アダマール行列とパスカル行列から作る整数の問題)では，答えが構成から厳密にわかる．乱数の行列では，正規方程式を有理数で解いて厳密な解を求める．
