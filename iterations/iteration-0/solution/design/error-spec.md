# 誤差仕様書

公開する関数ごとに，解く問題の条件数，アルゴリズムの誤差界，テストで使う許容誤差とその根拠，検証するテストを示す．
uは単位丸め(`Float64`では2⁻⁵³)，γₙ = nu/(1 − nu)である．
κ = Σ|xᵢ|/|Σxᵢ|は総和の条件数を表す．

## 前提

- 丸めは最近接偶数丸めで，オーバーフローは起きないとする．
- 丸め誤差の標準モデルfl(a ∘ b) = (a ∘ b)(1 + δ)，|δ| ≤ uを使う．加減算では，アンダーフローが起きてもこのモデルが成り立つ．
- 誤差界の中のκは，テストでは有理数で厳密に求めた値(`exact_condition_number`)を使う．

## 関数ごとの仕様

| 関数 | 問題の条件数 | 誤差界 | テストの許容誤差と根拠 | 検証するテスト |
| --- | --- | --- | --- | --- |
| `unit_roundoff` | なし(定数) | 誤差なし．eps(T)/2は2の冪である | 0(`==`で2⁻⁵³，2⁻²⁴と比べる) | `test/unit/error_bounds_tests.jl` |
| `gamma` | なし(定数) | nuは厳密，1 − nuと割り算で2回丸めるので相対誤差 ≤ γ₂ | γ₂(有理数で厳密に求めたγₙと比べる) | `test/unit/error_bounds_tests.jl` |
| `relative_error` | なし | 有理数で厳密に計算し，最後にFloat64へ1回丸める(相対誤差u以下) | 0(結果が厳密に表せる入力を`==`で比べる)，u(0.1の表現誤差が0より大きくu以下) | `test/unit/error_bounds_tests.jl` |
| `two_sum` | なし(無誤差変換) | a + b = s + eが厳密に成り立つ | 0(有理数に直して`==`で比べる) | `test/unit/summation_tests.jl` |
| `naive_sum` | κ | 相対誤差 ≤ γₙ₋₁·κ | γₙ₋₁·κ(誤差界そのもの) | `test/unit/summation_tests.jl`，`test/integration/summation_accuracy_tests.jl` |
| `compensated_sum` | κ | 相対誤差 ≤ u + γₙ₋₁²·κ | u + γₙ₋₁²·κ(誤差界そのもの) | `test/unit/summation_tests.jl`，`test/integration/summation_accuracy_tests.jl` |
| `sum_condition_number` | なし | 分子の相対誤差γₙ₋₁，分母の相対誤差β = u + γₙ₋₁²·κ，割り算の丸めu | (1 + γₙ₋₁)(1 + u)/(1 − β) − 1 + u(参照解を丸める分のuを加える) | `test/unit/summation_tests.jl` |

## 許容誤差の決め方

- 誤差界が厳密な不等式で示されているときは，誤差界をそのまま許容誤差にする．
- 誤差が積み重なる計算では，各段の相対誤差を(1 + ε₁)(1 + ε₂)⋯の形で掛け合わせて上界を作る．
- 結合テストでは，計算した条件数κ̂を使う．κ̂の相対誤差は約10⁻¹³以下で，γₙ₋₁の代わりにγₙを使うことで生まれる余裕(相対1/n程度)に収まる．
