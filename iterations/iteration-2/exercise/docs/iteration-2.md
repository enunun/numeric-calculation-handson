# Iteration 2の手順：分散と性質ベーステスト

このIterationでは，データの平均と標本分散を求める関数を作る．
教科書の公式がなぜ壊れるかを条件数で説明し，Welfordの算法で安定に計算する．
テストには，乱数のデータを使って性質を確かめる性質ベーステストと，入力の変換に対する出力の関係を確かめるメタモルフィックテストを書く．
作業はすべて`iterations/iteration-2/exercise/`で行う．

## 2-2 文法と概念

[Juliaのノート](../../../../docs/julia/iteration-2.md)と[理論のノート](../../../../docs/theory/iteration-2.md)を読み，REPLで次の課題を解く．

1. `Xoshiro(1)`から`rand`で3つの乱数を2回作り，同じ値になることを確かめる．シードを変えるとどうなるか．
2. `randn(Xoshiro(1), 1000)`の平均と標準偏差を，教科書の公式で計算する(ΣxᵢとΣxᵢ²を`for`文で足す)．
3. 2のデータに10⁸を足したデータ(ブロードキャストを使う)で，同じ計算をする．分散はどう変わるべきで，実際にはどうなるか．
4. `[1e9 + 4, 1e9 + 7, 1e9 + 13, 1e9 + 16]`の条件数‖x‖₂/√Sを，`Rational{BigInt}`で計算する．
5. `0.1 * 2.0^10 == 102.4`と`0.1 * 3 == 0.3`を確かめる．2の冪を掛けるときと，それ以外の数を掛けるときの違いを説明する．
6. `(1 + 1e-17) * (1 + 1e-17) - 1`を計算する．数学的な値と比べて何が起きたか．

## 2-3 テストリスト

次の要件と使用例を読み，`TESTLIST.md`に確かめる振る舞いを書き出す．

### 要件

- データの平均と標本分散を求める．
- 平均がばらつきより非常に大きいデータ(例：10⁹ + 小さな値)でも，分散を正確に求める．分散は負にならない．
- データを1回走査するだけで分散を求める(Welfordの算法)．
- 比較のため，教科書の公式(Σxᵢ² − (Σxᵢ)²/n)/(n − 1)による分散も計算できる．
- 分散の条件数を求められる．
- 分散では，要素数が2未満なら`ArgumentError`を投げる．平均では，空のデータで`ArgumentError`を投げる．

### 使用例

```julia
julia> data = [1e9 + 4, 1e9 + 7, 1e9 + 13, 1e9 + 16];

julia> mean(data), variance(data), textbook_variance(data)
(1.00000001e9, 30.0, -170.66666666666666)

julia> variance(fill(1e8 + 0.1, 3)), textbook_variance(fill(1e8 + 0.1, 3))
(0.0, 2.0)
```

### 作るもの

- `Moments`(新規)
  - `mean(xs::AbstractVector{T}) where {T<:AbstractFloat}`：和は`compensated_sum`で求める．
  - `variance(xs::AbstractVector{T}) where {T<:AbstractFloat}`：Welfordの算法．
  - `textbook_variance(xs::AbstractVector{T}) where {T<:AbstractFloat}`
  - `variance_condition_number(xs::AbstractVector{T}) where {T<:AbstractFloat}`：‖x‖₂/√S(Sは偏差平方和)を返す．S = 0なら`Inf`．

### 考えること

- 分散の参照解は，有理数で厳密に求められるか．
- 厳密に成り立つ性質(`==`や`>=`で比べられるもの)と，許容誤差つきで成り立つ性質を分けて書く．
- メタモルフィック関係(平行移動，並べ替え，拡大縮小)を検査するとき，入力の変換そのもので丸めが起きないようにするにはどうするか．
- 乱数で作るデータの条件数は，どの範囲に広げるべきか．教科書の公式の誤差界を検査するとき，条件数に上限は要るか．
- テストが失敗したとき，どのデータで失敗したかをどう知るか．
- 教科書の公式の「壊れ方」も，テストで記録しておく価値があるか．

## 2-5 テストファーストの実装

### テスト専用の依存

テストで`Random`を使うために，`Project.toml`の`[extras]`と`[targets]`に`Random`を加える．
`Random`のUUIDは，Juliaのノートの方法で調べる．
`[targets]`の`test`に加えないと，テストの実行時に`using Random`が失敗する．

### テストデータ

- `test/helpers.jl`に，乱数生成器`rng`を受け取ってデータを返す関数を置く．平均と標準偏差を引数で指定できると，条件数を制御できる．
- 平行移動の検査用に，丸めずに整数を足せるデータ(整数値のデータ)を作る関数も置く．
- シードの範囲(例えば1:50)を定数にして，性質ベーステストで共有する．
- 分散の参照解と条件数の参照解も，`test/helpers.jl`に置く．

### Moments

- `mean`のテストには，Iteration 0の総和のデータ(`SUM_DATASETS`)が使える．誤差界は，補償付き総和の誤差界と割り算の丸めから導く．
- `variance`は`enumerate`でデータの番号kを受け取りながら，平均と偏差平方和を更新する．
- `variance`の性質ベーステストは，`@testset "... seed = $(seed)" for seed in SEEDS`の形にする．
- `textbook_variance`は，Σxᵢ²とΣxᵢを1つの`for`文で足す．
- `variance_condition_number`は，有理数で‖x‖₂²とSを求め，`BigFloat`で平方根をとる．

### よくある間違い

- グローバルな乱数(`rand()`をシードなしで呼ぶ)を使う．失敗したデータを再現できない．
- 平行移動の検査で，`xs .+ 0.1`のように丸めの起きる値を足す．正しい分散そのものが変わってしまう．
- 許容誤差の式`(1 + β) * (1 + u) - 1`をそのまま計算する．1 + uが1に丸められて0になる．
- Welfordの更新で，Sの増分に更新前の平均だけを使う(`d * d`)．更新前の平均と更新後の平均の両方を使う形と，係数(k − 1)/kを掛ける形のどちらかにする．

## 2-7 発展課題

2つのデータの(要素数，平均，偏差平方和)から，2つをつないだデータの(要素数，平均，偏差平方和)を求める関数を作る(Chanの方法)．
データを分割して別々に計算し，最後に合わせる計算(並列計算)で使える．
「分割して合わせた結果は，つないだデータの分散と許容誤差の範囲で一致する」という性質を，分割位置を乱数で選んで検査する．
