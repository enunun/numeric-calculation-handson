# 誤差仕様書

公開する関数ごとに，解く問題の条件数，アルゴリズムの誤差界，テストで使う許容誤差とその根拠，検証するテストを示す．
uは単位丸め(`Float64`では2⁻⁵³)，γₙ = nu/(1 − nu)である．
κ = Σ|xᵢ|/|Σxᵢ|は総和の条件数を表す．
二次方程式p(x) = ax² + bx + cの根rについて，S(r) = |a|r² + |b||r| + |c|とし，次の2つを使う．

- 根の後退誤差η(r) = |p(r)|/S(r)：rを厳密な根とするように係数を相対的に変えるときの，変える量の最小値．
- 根の条件数κ_r = S(r)/|r·p′(r)|：係数の相対的な変化を，根の相対的な変化では何倍に拡大するか．

判別式の条件数をκ_d = (b² + 4|ac|)/|b² − 4ac|とする．

## 前提

- 丸めは最近接偶数丸めで，オーバーフローは起きないとする．積の無誤差変換と二次方程式では，アンダーフローも起きないとする．
- 丸め誤差の標準モデルfl(a ∘ b) = (a ∘ b)(1 + δ)，|δ| ≤ uを使う．平方根も同じモデルに従う．
- 誤差界の中のκは，テストでは有理数で厳密に求めた値(`exact_condition_number`)を使う．
- 二次方程式の参照解は，判別式を有理数で厳密に求め，256ビットの`BigFloat`で根の公式から計算する．

## quadratic_rootsの誤差界の導き方

絶対値の大きい根をr₁ = q/a，小さい根をr₂ = c/qで求める．q = −(b + sign(b)√d)/2である．

1. 判別式d̂の誤差は2 ulp以内である．1 ulpは相対2u以下なので，d̂の相対誤差は4u以下である．
2. √d̂の相対誤差は，dの誤差の半分(2u)と平方根の丸め(u)を合わせて3u以下である．
3. bとsign(b)√d̂は同符号なので，和で桁落ちは起きない．和の相対誤差は3u + u = 4u以下である．2で割るのは厳密である．
4. q/aとc/qの割り算でuずつ加わり，各根の相対誤差は5u以下になる．

二次の項を含めた上界として，テストではγ₆を使う．
判別式を素朴にb² − 4acと計算すると，2の段階でdの相対誤差が条件数に比例して大きくなり，この上界は成り立たない．

後退誤差は，根の相対誤差εから導く．r̂ = r(1 + ε)のとき，p(r̂) = r·ε·p′(r) + a·r²·ε²で，|r·p′(r)| ≤ 2S(r)なので，η ≤ 2ε + ε² ≤ γ₁₂である．

## 許容誤差の決め方

- 誤差界が厳密な不等式で示されているときは，誤差界をそのまま許容誤差にする．
- 誤差が積み重なる計算では，各段の相対誤差を(1 + ε₁)(1 + ε₂)⋯の形で掛け合わせて上界を作る．
- 結合テストでは，計算した条件数κ̂を使う．κ̂の相対誤差は約10⁻¹³以下で，γₙ₋₁の代わりにγₙを使うことで生まれる余裕(相対1/n程度)に収まる．
- 解と係数の関係は，参照解を使わずに検査する．各根の相対誤差をγ₆以下とすると，|r̂₁ + r̂₂ + b/a| ≤ (γ₆/(1 − γ₆))(|r̂₁| + |r̂₂|)，|r̂₁r̂₂ − c/a| ≤ γ₁₂|c/a|が成り立つ．左辺は`BigFloat`で計算する．
- 参照解の精度は，256ビットと512ビットで計算した値の相対差がu²以下であることで確かめる．参照解の誤差が許容誤差より十分小さくなければ，テストは実装の誤差を測れない．
