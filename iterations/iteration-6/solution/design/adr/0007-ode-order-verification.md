# ADR 0007：常微分方程式の解法は，製造解と収束次数で検証する

## 状況

常微分方程式の数値解は，打ち切り誤差のために厳密解と一致しない．
大域誤差の理論は「誤差 ≤ Chᵖ」という漸近的な主張で，定数Cは問題ごとに違い，事前にはわからない．
このため，ある刻み幅での誤差に固定の許容誤差を決めても，その値に根拠がない．
また，係数を1つ誤ったRK4でも，問題によっては1ステップの結果が正しい値と一致し，個々の値を比べるテストでは誤りが見つからない．

## 決定

- 検証には製造解を使う．先に解y*(t)を決め，非線形の右辺に強制項y*′(t) − g(t, y*(t))を加えて，y*がちょうど解になる問題を作る．
- 正しさの基準は収束次数とする．刻み幅を半分ずつにして観測次数p̂を求め，理論次数pとのずれを求める．hを半分にしたときのずれの比が0.6以下であることを確かめる．
- 打ち切り誤差だけを測るときは，同じ算法を`BigFloat`で実行する．`integrate`などは，要素の型によらず動く形で書く．
- 厳密解のわからない問題では，隣り合う刻み幅の解の差から観測次数を求める．

ほかの候補と比べた結果は次のとおりである．

- ある刻み幅での誤差を固定の許容誤差と比べる：許容誤差の根拠がない．次数の誤った実装も，刻み幅を十分小さくすれば合格してしまう．
- 標準的な問題の公表された数値解と比べる：比べる値そのものの精度を確かめる必要がある．
- 観測次数が理論次数から0.1以内であることを確かめる：0.1という値に根拠がなく，刻み幅の範囲によって合否が変わる．

## 結果

- 次数の誤りは，刻み幅を変えたときの誤差の減り方の違いとして確実に見つかる．
- 判定基準は漸近範囲でだけ使えるので，テストごとに刻み幅の範囲を選び，その範囲を記録する必要がある．
- `BigFloat`で実行する検査は遅いので，刻み幅の範囲を絞る(n ≤ 2⁹)．

## 検証

- 製造解の問題で，Euler法とRK4の観測次数のずれの比が0.6以下であることを，`BigFloat`の計算で検査する．
- `Float64`の丸め誤差が，同じ範囲で打ち切り誤差の1%以下であることを検査する．
- 厳密解が初等関数で書けない振り子の問題では，解の差から観測次数を求め，同じ基準を検査する．
- リチャードソン外挿の推定の相対誤差が，同じ基準で小さくなることを検査する．
