# ADR 0004：LU分解は部分ピボット選択を既定にし，受け入れ基準を後退誤差にする

## 状況

ガウスの消去法でLU分解を求めるとき，ピボット(各段で割る対角要素)が小さいと乗数lᵢₖ = aᵢₖ/aₖₖが大きくなる．
大きな乗数を掛けた行を引くとUの要素が大きくなり(増大因子ρの増加)，丸め誤差を拡大する．
`A = [1e-20 1; 1 1]`，`b = [1, 2]`では，ピボット選択なしの解は`[0.0, 1.0]`で，後退誤差は0.25である．

また，連立1次方程式の解の精度をテストで確かめるとき，前進誤差(厳密解との差)は行列の条件数に比例して大きくなる．
条件数が10¹³を超えるヒルベルト行列では，正しく実装しても前進誤差は10⁻⁴程度になる．

## 決定

- `lu_factorize`は，既定で部分ピボット選択をする．各段で，その列の対角より下で絶対値が最大の要素を持つ行と入れ替える．比較のため，`pivot = false`でピボット選択なしも選べる．
- 解の受け入れ基準は，Rigal–Gachesの後退誤差η = ‖b − Ax̂‖/(‖A‖·‖x̂‖ + ‖b‖)とする．上界はγ₃ₙ‖|L̂||Û|‖∞/‖A‖∞である．前進誤差は2κ(A)η/(1 − κ(A)η)で抑える．
- 後退誤差の残差は，有理数で厳密に計算する．

ほかの候補と比べた結果は次のとおりである．

- 完全ピボット選択(行と列の両方を入れ替える)：増大因子の上界はずっと小さいが，各段で残りの部分行列全体から最大値を探すので遅い．部分ピボット選択の増大因子が問題になる行列は，実用上まれである．
- 前進誤差に固定の許容誤差を使う：条件の悪い行列で，正しい実装が不合格になる．
- 残差を浮動小数点数で計算する：残差そのものの誤差で後退誤差を小さく見積もり，前進誤差の上界を破ることがある．

## 結果

- 乗数の絶対値は1以下になり，ω ≤ n²ρ，ρ ≤ 2ⁿ⁻¹である．多くの行列でρは小さく，後退誤差は単位丸め程度になる．
- 各段で列の最大値を探すので，比較がO(n²)回増える．分解全体のO(n³)に比べて小さい．
- 後退誤差の計算は有理数を使うので，大きな行列では遅い．テストで使う行列は12 × 12までにする．

## 検証

- 部分ピボット選択の分解で，Lの要素の絶対値が1以下であることと，|PA − L̂Û| ≤ γₙ|L̂||Û|が要素ごとに成り立つことを，乱数の行列(条件数1〜10¹²)で検査する．
- 後退誤差がγ₃ₙ‖|L̂||Û|‖∞/‖A‖∞以下で，前進誤差が2κη/(1 − κη)以下であることを，同じ行列とヒルベルト行列で検査する．
- Wilkinsonの行列で，増大因子が2ⁿ⁻¹になることを検査する．
- ピボット選択なしでは，(1, 1)要素の小さい行列で増大因子が大きくなり，後退誤差がピボット選択ありの上界を超えることを検査する．
