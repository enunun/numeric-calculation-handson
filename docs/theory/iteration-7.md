# Iteration 7：刻み幅の自動調整とシンプレクティック法

このノートでは，常微分方程式の2つの発展的な解き方を学ぶ．
1つは，局所誤差を推定して刻み幅を自動で決める方法である．
もう1つは，ハミルトン系の構造を保つシンプレクティック法で，長い時間の計算で保存量を保つ．
品質保証の面では，許容誤差が何を保証し何を保証しないか，保存量をどう検査するかを扱う．

## 1. 埋め込みルンゲ＝クッタ法

同じ傾きk₁, k₂, …から，次数の違う2つの解を作れるルンゲ＝クッタ法の組を，埋め込みルンゲ＝クッタ法と呼ぶ．
2つの解の差は，低い次数の解の局所誤差の推定になる．
傾きを追加で計算しないので，推定の費用は小さい．

Bogacki–Shampineの3(2)次の組では，次の4つの傾きを使う．

```text
k₁ = f(t, y)
k₂ = f(t + h/2, y + (h/2)k₁)
k₃ = f(t + 3h/4, y + (3h/4)k₂)
y₃ = y + h(2k₁ + 3k₂ + 4k₃)/9           (3次の解)
k₄ = f(t + h, y₃)
y₂ = y + h(7k₁ + 6k₂ + 8k₃ + 3k₄)/24    (2次の解)
```

推定はy₃ − y₂ = h(−5k₁ + 6k₂ + 8k₃ − 9k₄)/72である．
引き算で求めると桁落ちするので，係数をまとめた式で直接求める．

```julia
julia> f(t, y) = [y[2], -y[1]];

julia> bs32_step(f, 0.0, [1.0, 0.0], 0.1)
([0.995, -0.09983333333333333], [-2.0833333333335664e-6, -2.0833333333331656e-5])
```

推定は2次の解の誤差O(h³)を見積もるが，受理するのは精度の高い3次の解である．
これを局所外挿と呼ぶ．
受理した解の実際の局所誤差O(h⁴)は推定より小さい．

## 2. 刻み幅の制御

各成分の目標をatol + rtol·max(|yᵢ|, |y_newᵢ|)とし，推定を目標で割った値の2乗の平均の平方根をerrとする．
err ≤ 1ならステップを受理し，err > 1なら棄却して刻み幅を小さくし直す．

推定はh³に比例するので，errを1にする刻み幅はh·err^(−1/3)である．
安全のために0.9を掛け，急な変化を避けるために掛ける値を1/5以上5以下に制限する．

```text
h_new = h · min(5, max(1/5, 0.9·err^(−1/3)))
```

この式は，受理と棄却のどちらの場合にも次の刻み幅に使う．
最後のステップはt_endまでの残りに縮め，時刻にはt_endを代入する．t + hの丸めでt_endを越えないようにするためである．

## 3. 局所誤差と大域誤差

rtolとatolは，1ステップの局所誤差の目標である．
大域誤差は，各ステップの局所誤差が問題の性質に従って拡大または縮小されながらたまったものなので，tol以下になるとは限らない．

```julia
julia> y, accepted, rejected = integrate_adaptive(f, 0.0, [1.0, 0.0], 2π; rtol = 1e-8, atol = 1e-8);

julia> maximum(abs, y - [1.0, 0.0]), accepted, rejected
(1.8317103522846878e-7, 712, 2)
```

調和振動子を1周期解くと，大域誤差はtol = 10⁻⁸の約18倍である．
Iteration 6の製造解の問題では，tolを10⁻³から10⁻¹⁰まで変えたとき，大域誤差はいつもtolの約3.5〜3.9倍だった．

推定がh³に比例するので，刻み幅はtol^(1/3)にほぼ比例する．
受理する3次の解の大域誤差はh³に比例するので，大域誤差はtolにほぼ比例する．
したがって，テストで確かめられるのは「tolを小さくすると大域誤差が減る」という関係で，「大域誤差 ≤ tol」ではない．
保証されない性質をテストに書くと，問題を変えたときに正しい実装が不合格になる．
誤差仕様書には，テストしない性質とその理由も書く．

## 4. ハミルトン系とシンプレクティック写像

位置q，運動量pの系で，エネルギー(ハミルトニアン)がH(q, p) = ‖p‖²/2 + V(q)のとき，運動方程式は次のとおりである．

```text
q′ = p,   p′ = F(q) = −∇V(q)
```

厳密な解の流れは，次の2つの性質を持つ．

- エネルギーHを保つ．
- シンプレクティックである．1自由度では，(q, p)平面の面積を保つ(写像のヤコビ行列の行列式が1)．

数値解法の1ステップの写像がシンプレクティックなとき，その方法をシンプレクティック法と呼ぶ．

## 5. Störmer–Verlet法

```text
p_half = p + (h/2)F(q)
q_new  = q + h·p_half
p_new  = p_half + (h/2)F(q_new)
```

3つの式は，どれも行列式1のずらし(片方の変数だけをもう片方の関数だけ動かす)なので，合成もシンプレクティックである．
2次の方法で，hを−hに変えると1ステップ前に戻る(時間の反転に対して対称)．

```julia
julia> force(q) = -q;

julia> verlet_step(force, [1.0], [0.0], 0.5)
([0.875], [-0.46875])

julia> verlet_step(force, [0.875], [-0.46875], -0.5)
([1.0], [0.0])
```

中心力(F(q)はqに平行)なら，角運動量q × pを厳密に保つ．
p_halfとp_newへの変化はqまたはq_newに平行なので，q × pを変えないからである．

## 6. 修正エネルギー

Störmer–Verlet法はエネルギーHを厳密には保たない．
しかし，調和振動子(F(q) = −q)では，次の修正エネルギーH̃を厳密に保つ．

```text
H̃ = (p² + (1 − h²/4)q²)/2
```

H = H̃ + h²q²/8なので，q₀ = 1，p₀ = 0から始めると，エネルギーの誤差H − H₀は−h²/8以上0以下にとどまる．
何ステップ進めても，誤差はたまらない．

```julia
julia> q, p = verlet_integrate(force, [1.0], [0.0], 0.1, 1_000_000);

julia> (p[1]^2 + q[1]^2) / 2 - 0.5, 0.1^2 / 8
(-0.0006895751329086819, 0.0012500000000000002)

julia> (p[1]^2 + (1 - 0.1^2 / 4) * q[1]^2) / 2 - (1 - 0.1^2 / 4) / 2
8.698597397938101e-14
```

一般のハミルトン系でも，シンプレクティック法はh²の程度だけ違う修正エネルギーをほぼ保つ(後退誤差解析)．
そのため，エネルギーの誤差は非常に長い時間にわたって有界にとどまる．
数値解を「少しだけ違う問題の厳密解」とみなす考え方は，Iteration 1，3の後退誤差と同じである．

## 7. RK4のエネルギーの減衰

RK4を調和振動子に1ステップ適用すると，複素数q − ipにR(ih)を掛けることになる．
R(z) = 1 + z + z²/2 + z³/6 + z⁴/24はRK4の安定性関数である．
|R(ih)|² = 1 − h⁶/72 + h⁸/576 < 1なので，エネルギーはステップごとに一定の割合で減る．

```julia
julia> let y = [1.0, 0.0]
           for _ in 1:1_000_000
               y = rk4_step(f, 0.0, y, 0.1)
           end
           (y[1]^2 + y[2]^2) / 2 - 0.5
       end
-0.006887880775824584

julia> h = big(1) // 10; ((1 - h^2 / 2 + h^4 / 24)^2 + (h - h^3 / 6)^2)^1_000_000 / 2 - big(1) // 2 |> Float64
-0.006887880775504699
```

1周期の誤差はRK4のほうがずっと小さいが，10⁶ステップ後のエネルギーの誤差は，同じ時点のStörmer–Verlet法の誤差の約10倍になる．
長い時間の計算では，次数より保存の性質が効く．

## 8. 保存量による検査

保存量は，参照解なしで長い時間の計算を検査できるオラクルである．
ただし，`Float64`で計算すると丸め誤差で保存量は少しずつ変わるので，その上界を導く．

1. 厳密な写像が保存量を保つなら，各ステップの丸め誤差による変化は，その後のステップで変わらずに残る．
2. 1ステップの変化を，Iteration 0と同じ標準モデルで見積もる．調和振動子では，修正エネルギーは6u，円軌道の角運動量は12u以下しか変わらない(誤差仕様書)．
3. nステップの変化は，6nu，12nu以下である．許容誤差にはγ₆ₙ，γ₁₂ₙを使う．

保存量を`Float64`で評価すると評価の丸め誤差が混ざるので，テストでは`BigFloat`で評価する．
有理数で計算すれば丸め誤差がないので，厳密に保たれる量は`==`で検査できる．

厳密解も保存量の上界もわからない問題(ケプラー問題)では，誤差の増え方を検査する．
エネルギーの誤差の最大値を区間[0, T]と[0, 10T]で比べると，誤差が有界なら比はほぼ1，時間に比例してたまるなら比はほぼ10になる．
2つの仮説の幾何平均√10を境にすれば，どちらの仮説にも同じ比率の余裕がある．

保存量の検査で見つからない間違いもある．
p_halfをp + h·F(q)とした(半分にし忘れた)実装を考える．これもずらしの合成なのでシンプレクティックで，中心力の角運動量も保つ．
この間違いは，観測次数とエネルギーの誤差の上界の検査で見つかる．
