# Iteration 6：常微分方程式と収束次数

このノートでは，常微分方程式の初期値問題を一段法で解くときの誤差を学ぶ．
誤差の大きさそのものではなく「刻み幅を小さくしたときの誤差の減り方(収束次数)」で解法の正しさを検証する方法を扱う．

## 1. 初期値問題と一段法

初期値問題は，関数y(t)(一般にベクトル)について次の形で表される．

```text
y′(t) = f(t, y(t)),   y(t₀) = y₀
```

区間[t₀, t_end]をn等分し，刻み幅h = (t_end − t₀)/nで，yₖ ≈ y(t₀ + kh)を順に求める．
yₖ₊₁をyₖだけから求める方法を一段法と呼ぶ．

- Euler法：yₖ₊₁ = yₖ + h·f(tₖ, yₖ)．接線の方向にhだけ進む．
- 古典的な4次のルンゲ＝クッタ法(RK4)：区間の始め，中点(2回)，終わりの4か所の傾きk₁, …, k₄を求める．それらを重み(1/6, 2/6, 2/6, 1/6)で平均した傾きの方向に進む．

右辺がtだけの関数なら，RK4はシンプソンの公式による積分と同じになり，3次以下の多項式を厳密に積分する．

## 2. 局所誤差と大域誤差

厳密解の上から1ステップ進んだときの誤差を局所打ち切り誤差と呼ぶ．
Euler法ではテイラー展開y(t + h) = y(t) + hy′(t) + h²y″(t)/2 + ⋯から，局所誤差はO(h²)である．
RK4の局所誤差はO(h⁵)である．

t_endまでにn = (t_end − t₀)/hステップ進むので，局所誤差O(hᵖ⁺¹)がn回分たまって，大域誤差(t_endでの誤差)はO(hᵖ)になる．
このpを方法の次数と呼ぶ．Euler法は1次，RK4は4次である．
局所誤差は，その後のステップで問題の性質に従って拡大または縮小されながら伝わる．その度合いは問題によって違い，大域誤差の定数に現れる．

```julia
julia> f(t, y) = [y[2], -y[1]];

julia> e(n, step) = maximum(abs, integrate(step, f, 0.0, [1.0, 0.0], 2π, n) - [1.0, 0.0]);

julia> e(100, euler_step), e(200, euler_step)
(0.21770684198423074, 0.10367468781049172)

julia> e(100, rk4_step), e(200, rk4_step)
(8.149021641923326e-7, 5.098530393016221e-8)
```

調和振動子y″ = −yを1周期解くと，刻み幅を半分にしたとき，Euler法の誤差はほぼ半分に，RK4の誤差はほぼ1/16になる．

## 3. 収束次数による検証

大域誤差の理論は「e(h) ≤ Chᵖ」の形で，定数Cは問題ごとに違い，事前にはわからない．
そのため，ある刻み幅での誤差の大きさから「正しく実装できているか」を判断するのは難しい．
代わりに，刻み幅をhとh/2にしたときの誤差の比から観測次数p̂を求め，理論次数と比べる．

```text
p̂ = log₂(e(h) / e(h/2))
```

```julia
julia> observed_order(e(100, euler_step), e(200, euler_step)), observed_order(e(100, rk4_step), e(200, rk4_step))
(1.0703230456058292, 3.9984734943214324)
```

次数の検証は，数値解法の検証の標準的な方法である．
係数を1つ誤ったRK4でも，テイラー展開の低次の項は合っていることが多く，1ステップの値を比べるテストでは見つからない．
観測次数を測れば，「4次のはずが2次になっている」ことがはっきりわかる．

## 4. 観測次数の判定基準

観測次数はpにちょうど一致するわけではない．大域誤差が次のように展開できるとする．

```text
e(h) = C hᵖ (1 + D h + O(h²))
```

このとき，観測次数は次のようになる．

```text
p̂ = p + log₂((1 + Dh)/(1 + Dh/2)) + O(h²) = p + Dh/(2 ln 2) + O(h²)
```

ずれ|p̂ − p|はhにほぼ比例するので，hを半分にするとほぼ半分になる．
このコースでは，ずれの比が1/2に高次の項の分の余裕を加えた0.6以下であることを判定基準にする．
「|p̂ − p| ≤ 0.1」のような基準と違い，基準の値を漸近展開から説明でき，刻み幅の範囲を変えても意味が変わらない．
次数の誤った実装では，ずれは理論次数との差(例えば4 − 2 = 2)に近づくので，比は1に近づき，基準を満たさない．

この基準は，展開の高次の項が小さい範囲(漸近範囲)でだけ使える．
hが大きいと，ずれが一度0に近づいてから増えるなど，半分ずつにはならない．
振り子をEuler法で解くと，n = 2⁷までは漸近範囲に入らない．テストでは，使う刻み幅の範囲を選んで記録する．

## 5. 製造解

収束次数を測るには，厳密解が要る．
Iteration 4の製造解と同じ考え方で，答えから問題を作る．

1. 解y*(t)を先に決める．このコースではy*(t) = (sin t, e⁻ᵗcos 2t)とする．
2. 調べたい形の右辺g(t, y)を決める．非線形の項を含めると，解法の非線形の部分も検査できる．
3. 強制項を加えて，f(t, y) = g(t, y) + (y*′(t) − g(t, y*(t)))とする．

f(t, y*(t)) = y*′(t)なので，y*はちょうどこの問題の解である．
製造解の方法では，問題の物理的な意味は問わない．解法のすべての部分(非線形の右辺，複数の成分，時刻への依存)を使う問題を作ることが目的である．

## 6. 丸め誤差と打ち切り誤差を分ける

刻み幅を小さくすると打ち切り誤差は減るが，ステップ数が増えるので丸め誤差がたまる．
RK4で調和振動子を解くと，n = 10⁴のあたりで誤差は最小になり，それより細かくすると増える．

```julia
julia> [e(n, rk4_step) for n in (10^2, 10^3, 10^4, 10^5, 10^6)]
5-element Vector{Float64}:
 8.149021641923326e-7
 8.160481752145232e-11
 7.370731629208205e-15
 1.606230610757403e-14
 1.5155409106772533e-14
```

丸め誤差が無視できない範囲で観測次数を測ると，次数が見かけ上下がる．
そこで，同じ算法を`BigFloat`で実行し，丸め誤差を取り除いて打ち切り誤差だけを測る．
`integrate`を要素の型によらず書いておけば，`BigFloat`の初期値を渡すだけでよい．

```julia
julia> g = (t, y) -> -2y;

julia> integrate(rk4_step, g, big(0.0), [big(1.0)], big(1.0), 10)
1-element Vector{BigFloat}:
 0.135339548430510116620208891634063409233992487595048180324814984165692899117681
```

これは「高精度で同じ算法を実行する」という参照解の作り方で，Iteration 1の高精度の参照解(問題の厳密解)とは目的が違う．
`Float64`の結果との差は丸め誤差，厳密解との差は打ち切り誤差である．
テストでは，`Float64`の丸め誤差が打ち切り誤差の1%以下であることも確かめる．その範囲なら，観測次数への影響は0.015以下である．

## 7. リチャードソン外挿

p次の方法で，刻み幅h，h/2の解y_h，y_{h/2}を求めたとする．
y_h − y ≈ Chᵖ，y_{h/2} − y ≈ Chᵖ/2ᵖなので，細かい解の誤差は次のように推定できる．

```text
y_{h/2} − y ≈ (y_h − y_{h/2}) / (2ᵖ − 1)
```

```julia
julia> maximum(abs, richardson_error_estimate(y100, y200, 4)), maximum(abs, y200 - [1.0, 0.0])
(5.09277906841447e-8, 5.098530393016221e-8)
```

推定の相対誤差もO(h)なので，観測次数と同じ基準で検査できる．
ただし，誤差の主要な項の次数は成分によって違うことがある．
RK4で調和振動子を解くと，位相の誤差はh⁴に，振幅の誤差はh⁵に比例するので，振幅の影響が大きい成分では推定が合わない．
推定は誤差の大きさの見積もりで，保証ではない．

## 8. 厳密解を使わない収束の検査

厳密解がわからない問題でも，3つ以上の刻み幅の解から収束次数を確かめられる．
y_h − y_{h/2} ≈ Chᵖ(1 − 2⁻ᵖ)なので，隣り合う差の比も2ᵖに近づく．
振り子y″ = −sin yのように，厳密解が初等関数で書けない問題に使う．
