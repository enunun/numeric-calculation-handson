各Iterationで学ぶ数値計算の理論をまとめる．

| Iteration | ノート | 主な内容 |
| --- | --- | --- |
| 0 | [浮動小数点数と総和の誤差](iteration-0.md) | IEEE 754，単位丸め，標準モデル，γₙ，条件数，総和の誤差解析，TwoSum，Sum2，許容誤差の設計，厳密な参照解 |
| 1 | [桁落ち，後退誤差，条件数](iteration-1.md) | 桁落ちとSterbenzの補題，根の公式の書き換え，fmaとTwoProd，Kahanの判別式，前進誤差と後退誤差，根の条件数，高精度の参照解，解と係数の関係 |
