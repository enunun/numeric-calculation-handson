| Iteration | ノート | 主な内容 |
| --- | --- | --- |
| 0 | [浮動小数点数と総和の誤差](iteration-0.md) | IEEE 754，単位丸め，標準モデル，γₙ，条件数，総和の誤差解析，TwoSum，Sum2，許容誤差の設計，厳密な参照解 |

| 6 | [常微分方程式と収束次数](iteration-6.md) | 初期値問題と一段法，局所誤差と大域誤差，Euler法とRK4，観測次数，漸近展開による判定基準，漸近範囲，製造解，丸め誤差と打ち切り誤差の分離，リチャードソン外挿，厳密解を使わない収束の検査 |
| 7 | [刻み幅の自動調整とシンプレクティック法](iteration-7.md) | 埋め込みルンゲ＝クッタ法，刻み幅の制御，局所誤差と大域誤差，ハミルトン系，Störmer–Verlet法，修正エネルギー，RK4のエネルギーの減衰，保存量による検査と丸め誤差の上界 |
