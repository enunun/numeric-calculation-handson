# Iteration 3：LU分解と後退安定性

このノートでは，連立1次方程式Ax = bをガウスの消去法(LU分解)で解くときの誤差を学ぶ．
Iteration 1で学んだ「前進誤差 ≲ 条件数 × 後退誤差」を行列に広げ，後退誤差を残差から計算してテストに使う．

## 1. ノルム

ベクトルや行列の大きさをノルムで測る．このノートでは主に∞ノルムを使う．

```text
‖x‖∞ = maxᵢ |xᵢ|
‖A‖∞ = maxᵢ Σⱼ |aᵢⱼ|   (行ごとの絶対値の和の最大値)
```

行列の∞ノルムは，ベクトルの∞ノルムから導かれる作用素ノルムで，‖Ax‖∞ ≤ ‖A‖∞‖x‖∞を満たす．
2ノルム‖x‖₂ = √(Σxᵢ²)と，それから導かれる行列の2ノルム(最大特異値)もよく使う．
Iteration 4では2ノルムを使う．

```julia
julia> norm([3.0, -4.0]), norm([3.0, -4.0], Inf), opnorm([1.0 -2.0; 3.0 4.0], Inf)
(5.0, 4.0, 7.0)
```

## 2. 行列の条件数

Ax = bで，Aとbを相対ε以下だけ変えたとき，解xの相対的な変化は，一次の近似で次のように抑えられる．

```text
‖Δx‖/‖x‖ ≲ 2κ(A) ε,   κ(A) = ‖A‖ ‖A⁻¹‖
```

κ(A)を行列の条件数と呼ぶ．κ(A) ≥ 1で，Aが特異に近いほど大きい．
ヒルベルト行列(i, j要素が1/(i + j − 1))は，条件数が非常に大きい行列の代表例である．
10 × 10のヒルベルト行列の∞ノルムの条件数は約3.5 × 10¹³である．

```julia
julia> cond(H, Inf)
3.535432091711151e13
```

## 3. 後退誤差と残差

計算した解x̂の後退誤差は，x̂を厳密な解とする問題(A + ΔA)x̂ = b + Δbのうち，変化が最も小さいものの大きさである．
Rigal–Gachesの定理によれば，‖ΔA‖ ≤ η‖A‖，‖Δb‖ ≤ η‖b‖を満たす最小のηは次の式で表される．

```text
η(x̂) = ‖b − Ax̂‖ / (‖A‖ ‖x̂‖ + ‖b‖)
```

分子は残差r = b − Ax̂のノルムである．
残差は，厳密解を知らなくても計算できる．
これが，連立1次方程式のテストで後退誤差を使う最大の理由である．

残差の計算には注意が要る．
浮動小数点数で計算した残差には，約γₙ₊₁(‖A‖·‖x̂‖ + ‖b‖)の誤差が入る．
後退誤差が単位丸め程度のとき，残差の計算誤差は残差そのものと同じ大きさになり，後退誤差を正しく測れない．
`backward_error`は残差を有理数で厳密に計算する．

```julia
julia> A = [1e-20 1.0; 1.0 1.0]; b = [1.0, 2.0];

julia> backward_error(A, [0.0, 1.0], b), backward_error(A, [1.0, 1.0], b)
(0.25, 2.5e-21)

julia> A * [1.0, 1.0] - b
2-element Vector{Float64}:
 0.0
 0.0
```

浮動小数点数で計算した残差は0だが，(1, 1)は厳密解ではない．厳密な残差は(−10⁻²⁰, 0)である．

## 4. ガウスの消去法とLU分解

ガウスの消去法は，Aを対角が1の下三角行列Lと上三角行列Uの積A = LUに分解する．
k段目では，k列目の対角より下の要素を0にする．そのため，乗数lᵢₖ = aᵢₖ/aₖₖを掛けたk行目をi行目から引く．
分解できたら，Ly = bを前進代入で，Ux = yを後退代入で解く．

## 5. Wilkinsonの後退誤差解析

Wilkinsonは，ガウスの消去法の誤差を後退誤差として解析した．

1. 計算したL̂，Ûは，L̂Û = A + ΔA，|ΔA| ≤ γₙ|L̂||Û|を満たす(Higham，定理9.3)．|·|は要素ごとの絶対値で，不等式も要素ごとである．
2. 前進代入と後退代入も後退安定なので，計算した解x̂は(A + ΔA)x̂ = b，|ΔA| ≤ γ₃ₙ|L̂||Û|を満たす(定理9.4)．

∞ノルムをとると，後退誤差は次のように抑えられる．

```text
η ≤ γ₃ₙ ω,   ω = ‖|L̂||Û|‖∞ / ‖A‖∞
```

ωは，分解の結果から計算できる量である．
ωが小さければ，ガウスの消去法は後退安定である．
ωが大きくなるのは，L̂やÛの要素がAの要素に比べて大きくなるとき，つまり小さなピボットで割ったときである．

## 6. ピボット選択と増大因子

ピボットが小さいと，乗数lᵢₖが大きくなる．
極端な例は`[1e-20 1; 1 1]`である．
ピボット選択なしでは，乗数は10²⁰で，Uの(2, 2)要素は1 − 10²⁰になる．
1の情報が丸めで失われ，解は(0, 1)になる．後退誤差は0.25で，単位丸めよりはるかに大きい．

```julia
julia> F = lu_factorize(A; pivot = false)
StableNumerics.LinearSolve.LUFactorization{Float64}([1.0e-20 1.0; 1.0e20 -1.0e20], [1, 2])

julia> solve(F, b), growth_factor(F, A)
([0.0, 1.0], 1.0e20)
```

部分ピボット選択では，各段で，k列目の対角より下で絶対値が最大の要素を持つ行をk行目と入れ替える．
すると，乗数の絶対値は1以下になる．

```julia
julia> G = lu_factorize(A)
StableNumerics.LinearSolve.LUFactorization{Float64}([1.0 1.0; 1.0e-20 1.0], [2, 1])

julia> solve(G, b), growth_factor(G, A)
([1.0, 1.0], 1.0)
```

乗数の絶対値が1以下なら，|L̂||Û|の各要素はn·maxᵢⱼ|ûᵢⱼ|以下なので，ω ≤ n²ρである．
ここでρ = maxᵢⱼ|ûᵢⱼ|/maxᵢⱼ|aᵢⱼ|は増大因子である．

部分ピボット選択でも，ρは最悪2ⁿ⁻¹になりうる．
対角が1，対角より下が−1，最後の列が1の行列(Wilkinsonの例)では，ちょうど2ⁿ⁻¹になる．
しかし，実際に現れる行列でρが大きくなることはまれで，部分ピボット選択のガウスの消去法は「実用上は後退安定」とされる．

## 7. 前進誤差の上界

後退誤差ηと条件数κ(A)から，前進誤差は次のように抑えられる．κ(A)η < 1を仮定する．

```text
‖x̂ − x‖ / ‖x‖ ≤ 2κ(A)η / (1 − κ(A)η)
```

ヒルベルト行列で確かめる．後退誤差は単位丸めより小さい．

```julia
julia> x = solve(lu_factorize(H), b);

julia> backward_error(H, x, b)
4.7801527578771173e-17

julia> maximum(abs, x .- 1)
0.0007048053783595964
```

bはH × (1, 1, …, 1)を浮動小数点数で計算した値なので，丸めが入っている．
そのためHx = bの厳密解は(1, 1, …, 1)ではなく，それから10⁻⁴〜10⁻³程度ずれている(bの相対u程度の変化が，κ(H)倍に拡大されるからである)．
上の`maximum(abs, x .- 1)`は(1, 1, …, 1)との差で，有理数で求めた厳密解と比べた前進誤差は約2.3 × 10⁻⁴である．
κη ≈ 3.5 × 10¹³ × 4.8 × 10⁻¹⁷ ≈ 1.7 × 10⁻³なので，上界は約3.4 × 10⁻³であり，実際の前進誤差はその中に収まる．
テストで前進誤差を測るときは，「たぶん正しい答え」ではなく，与えた問題の厳密解と比べる．

## 8. テストの設計

この理論から，連立1次方程式のテストの方針が決まる．

- アルゴリズムの安定性は後退誤差で検査する．許容誤差はγ₃ₙωで，ωは分解の結果から計算する．
- 前進誤差は2κη/(1 − κη)で検査する．固定の許容誤差を使うと，条件の悪い行列で正しい実装が不合格になる．ヒルベルト行列では，前進誤差はγ₃ₙの10¹⁰倍以上になる．
- 分解そのものは，要素ごとの不等式|PA − L̂Û| ≤ γₙ|L̂||Û|で検査する．この不等式は分解の再構成の検査で，解を求めなくても確かめられる．
- 参照解(厳密解，厳密な条件数)は有理数で求める．浮動小数点数の行列はすべて有理数の行列なので，有理数のガウスの消去法で厳密に計算できる．

## 9. 条件数を指定したテスト行列

誤差界を検査するには，条件数の小さい行列から大きい行列まで，さまざまな行列が要る．
特異値分解A = UΣVᵀを逆に使うと，条件数を指定した行列を作れる．

1. 乱数の行列のQR分解で，直交行列U，Vを作る．
2. 特異値σᵢを1からκ⁻¹まで等比的に並べた対角行列Σを作る．
3. A = UΣVᵀとする．

2ノルムの条件数はσ₁/σₙ = κになる．
浮動小数点数で計算するので，できた行列の条件数はκと少しずれる．テストでは，できた行列の条件数を有理数で計算し直して使う．

条件数のほかに，構造の違う行列も含める．

- ヒルベルト行列：条件数が非常に大きい．
- Wilkinsonの行列：部分ピボット選択の増大因子が最大になる．
- (1, 1)要素の小さい行列：ピボット選択の有無で結果が大きく変わる．
