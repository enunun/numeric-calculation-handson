# Iteration 4：最小二乗法と直交変換

このノートでは，最小二乗問題min‖Ax − b‖₂を，正規方程式とQR分解の2つの方法で解いたときの誤差を比べる．
直交変換が誤差を拡大しない理由を学び，答えから問題を作る製造解の方法でテストする．

## 1. 最小二乗問題

m × n行列A(m > n)とm次元のベクトルbについて，‖Ax − b‖₂を最小にするxを求める問題を最小二乗問題と呼ぶ．
データ(tᵢ, yᵢ)への多項式の当てはめは，ヴァンデルモンド行列Vᵢⱼ = tᵢ^(j−1)についての最小二乗問題である．

最小二乗解xでは，残差r = b − Axが，Aのすべての列と直交する．

```text
Aᵀr = 0   ⇔   AᵀAx = Aᵀb   (正規方程式)
```

列フルランク(列が1次独立)の行列Aでは，最小二乗解はただ1つに決まる．

## 2. 2ノルムと条件数

最小二乗問題では2ノルムを使う．行列の2ノルム‖A‖₂は最大特異値σ_maxで，2ノルムの条件数は次の式で表される．

```text
κ₂(A) = σ_max / σ_min
```

直交行列Q(QᵀQ = I)を掛けても，ベクトルの2ノルムは変わらない(‖Qx‖₂ = ‖x‖₂)．
このため，直交行列を掛ける変換は，誤差を拡大しない．

## 3. 正規方程式

正規方程式AᵀAx = Aᵀbは，n × nの連立1次方程式なので，Iteration 3のLU分解で解ける．
しかし，AᵀAの特異値はAの特異値の2乗なので，条件数も2乗になる．

```text
κ₂(AᵀA) = κ₂(A)²
```

```julia
julia> cond(V), cond(V' * V)
(3.5589445051546474e6, 1.2665254681837176e13)
```

AᵀAを作った時点で，Aの情報は相対u程度の誤差を含む．その誤差がκ₂(A)²倍に拡大されるので，前進誤差はκ₂(A)²u程度になる．
κ₂(A)²u ≥ 1なら，正しい桁は残らない．

## 4. ハウスホルダー変換とQR分解

単位ベクトルvについて，H = I − 2vvᵀをハウスホルダー変換と呼ぶ．
Hは対称な直交行列で，vに垂直な超平面についての鏡映である．

ベクトルxを，e₁ = (1, 0, …, 0)の方向のαe₁(|α| = ‖x‖₂)に写すHは，v = (x − αe₁)/‖x − αe₁‖₂で作れる．
αの符号は，−sign(x₁)に選ぶ．x₁とαが同符号だと，xがe₁とほぼ平行な場合，x₁ − αの計算で桁落ちが起きるからである．

k段目で，k列目のk行目より下の部分をαₖe₁に写すHₖを作り，行列の残りの部分に掛ける．
n段で上三角行列Rが残り，A = QR，Q = H₁H₂⋯Hₙとなる．

## 5. QR分解による最小二乗法

A = QRなら，Qが直交行列であることから次の式が成り立つ．

```text
‖Ax − b‖₂ = ‖Qᵀ(Ax − b)‖₂ = ‖Rx − Qᵀb‖₂
```

Rの下のm − n行は0なので，Rx = (Qᵀb)の最初のn成分を後退代入で解けば，最小二乗解が得られる．
Qᵀbは，ハウスホルダーベクトルを順に作用させて求める．Qを行列として作る必要はない．

## 6. QR分解の誤差

ハウスホルダー変換によるQR分解は後退安定である(Higham，定理19.4)．
計算したR̂とQ̂について，A + ΔA = Q̂R̂(Q̂は厳密に直交する行列)が成り立ち，列ごとに‖Δaⱼ‖₂ ≤ γ̃ₘₙ‖aⱼ‖₂である．
γ̃ₘₙ = c·mn·u/(1 − c·mn·u)のcは小さな定数で，具体的な値は示されていない．

最小二乗解も後退安定で，計算した解は，Aとbを列ごとに相対γ̃ₘₙ程度だけ変えた問題の厳密な最小二乗解である(定理20.3)．
最小二乗問題の摂動論(Wedin)から，前進誤差は一次の近似で次のようになる．

```text
‖x̂ − x‖₂/‖x‖₂ ≲ γ̃ₘₙ (κ₂ + κ₂² ρ),   ρ = ‖r‖₂ / (‖A‖₂ ‖x‖₂)
```

残差が小さい問題(ρ ≈ 0)では，誤差はκ₂に比例する．
残差が大きい問題では，QR分解でも誤差がκ₂²に比例する．これは問題そのものの感度であり，アルゴリズムでは避けられない．
正規方程式の誤差は，残差の大きさと関係なくκ₂²に比例する．

## 7. 定数のわからない誤差界

γ̃ₘₙの定数cがわからないので，誤差界をそのまま許容誤差にはできない．
このコースでは，Iteration 2のWelfordの算法と同じく，次のように扱う．

1. c = 1とした一次の見積もりmn·u(κ₂ + κ₂²ρ)を基準にする．
2. 見積もりに2倍の余裕を持たせたγ₂ₘₙ(κ₂ + κ₂²ρ)を許容誤差にする．
3. 乱数の行列と製造解で測った値(基準に対して最大0.64倍)と，見積もりであることを誤差仕様書に書く．

## 8. 製造解

テストには，正しい答えのわかっている問題が要る．
製造解(manufactured solution)の方法では，先に答えを決め，そこから問題を作る．

最小二乗問題では，解xと，Aの列と直交する残差rを先に決める．b = Ax + rとすれば，xがbの最小二乗解になる．
ただし，浮動小数点数でAx + rを計算すると丸めが入り，xは厳密な解ではなくなる．
rとAの列の直交性も，丸めで崩れる．

模範解答では，すべての値が小さな整数になるように問題を作る．

- アダマール行列H(要素は±1，列どうしが直交する)を，シルベスターの構成(Hₖから`[H H; H -H]`でH₂ₖを作る)で作る．
- Hの最初のn列に上三角のパスカル行列P(要素は二項係数)を掛けてA = H₁Pとする．Pは条件数をnとともに大きくする．
- xを小さな整数のベクトル，rをHの残りの列の小さな整数係数の組み合わせとする．rは，Aのどの列とも厳密に直交する．

どの値も小さな整数なので，Ax + rは丸めずに計算できる．最小二乗解は厳密にxで，残差は厳密にrである．
同じ考え方で，整数の点での整数係数の多項式の値から，多項式の当てはめの製造解も作れる．

製造解のほかに，乱数の行列では正規方程式を有理数で解いて厳密な最小二乗解を求める．
有理数では丸めがないので，κ₂²の問題は起きない．

## 9. 最適性条件と直交性の検査

最小二乗解の性質Aᵀr = 0は，参照解を使わずに検査できる．
計算した解x̂の残差r̂ = b − Ax̂について，‖Aᵀr̂‖₂が‖A‖₂(‖A‖₂‖x̂‖₂ + ‖b‖₂ + ‖r̂‖₂)に比べて小さいことを確かめる．

QR分解そのものも，解を求めずに検査できる．

- 直交性：‖Q̂ᵀQ̂ − I‖₂が小さい．
- 再構成：列ごとに‖aⱼ − (Q̂R̂)ⱼ‖₂が‖aⱼ‖₂に比べて小さい．

これらの検査は，Iteration 3のLU分解の再構成の検査と同じ役割を持つ．

## 10. 弱点を狙ったテストデータ

αの符号を逆にした実装は，乱数の行列のテストにすべて合格する．
符号の誤りで桁落ちが起きるのは，列がe₁にほぼ平行なとき(第1要素がほかの要素よりずっと大きいとき)だけで，乱数の行列ではまず起きないからである．

理論から「この場合に壊れる」とわかる入力は，乱数に任せず，狙って作る．
模範解答では，第1要素が±1，ほかの要素が10⁻⁴〜10⁻¹²の列を持つ行列で，直交性と再構成を検査する．

## 11. リファクタリングの安全網

このIterationでは，`LinearSolve`の前進代入と後退代入を`Triangular`へ移す．
移した後も`LinearSolve`のテストが変わらずに通ることが，振る舞いが変わっていないことの保証になる．
テストがリファクタリングの安全網になるのは，テストが関数の内部の作りではなく，外から見た振る舞い(誤差界)を検査しているからである．
