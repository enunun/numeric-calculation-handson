# Iteration 2：分散の計算と性質ベーステスト

このノートでは，標本分散の3つの計算方法を誤差の観点から比べる．
あわせて，参照解がなくても検査できる性質ベーステストとメタモルフィックテストの考え方を学ぶ．

## 1. 分散と条件数

データx₁, …, xₙの平均をx̄ = Σxᵢ/n，偏差平方和をS = Σ(xᵢ − x̄)²とする．
標本分散はS/(n − 1)である．

各xᵢをxᵢ(1 + εᵢ)，|εᵢ| ≤ εに変えたときのSの変化を考える．
∂S/∂xᵢ = 2(xᵢ − x̄)なので，一次の近似で次の不等式が成り立つ．

```text
|ΔS| ≤ 2ε Σ|xᵢ||xᵢ − x̄| ≤ 2ε ‖x‖₂ √S
```

最後の不等式はコーシー・シュワルツの不等式である．両辺をSで割ると，|ΔS|/S ≤ 2ε·‖x‖₂/√Sになる．
そこで，分散の条件数を次のように定める(Chan，Golub，LeVeque)．

```text
κ_v = ‖x‖₂ / √S
```

κ_v ≥ 1で，平均が標準偏差に比べて大きいほどκ_vは大きい．およそκ_v ≈ √(1 + (x̄/σ)²)である．
`[1e9 + 4, 1e9 + 7, 1e9 + 13, 1e9 + 16]`の条件数は約2.1 × 10⁸である．

```julia
julia> variance_condition_number(data)
2.1081851278607705e8
```

## 2. 教科書の公式

数学的にはS = Σxᵢ² − (Σxᵢ)²/nなので，データを1回走査してΣxᵢ²とΣxᵢを足し合わせれば分散が求まる．
しかし，κ_vが大きいとΣxᵢ²と(Σxᵢ)²/nはほぼ等しく，引き算で桁落ちが起きる．
2つの項はどちらも丸めた値なので，有害な桁落ちである．

誤差を見積もる．Q = Σxᵢ²，T = Σxᵢとする．

1. Qは非負の数の和なので，相対誤差はγₙ以下である．
2. Tの絶対誤差はγₙ₋₁Σ|xᵢ|以下である．|T|Σ|xᵢ|/n ≤ (Σ|xᵢ|)²/n ≤ Q(コーシー・シュワルツの不等式)なので，T²/nの絶対誤差は一次の近似で(2γₙ₋₁ + 2u)Q以下である．
3. 引き算とn − 1での割り算で，さらに2uが加わる．

Q = ‖x‖₂² = κ_v²·Sなので，Sの相対誤差は一次の近似で次のようになる．

```text
相対誤差 ≲ (3n + 1)u · κ_v² + 2u
```

誤差はκ_vの**2乗**に比例する．
条件数κ_vの問題を解くのに，誤差をκ_v²倍に拡大するアルゴリズムは，問題が要求する以上に不安定である．
κ_v ≈ 10⁸ではκ_v²u ≈ 1なので，正しい桁は1つも残らない．
実際，正しい分散が30.0のデータで負の値を返す．

```julia
julia> mean(data), variance(data), textbook_variance(data)
(1.00000001e9, 30.0, -170.66666666666666)
```

## 3. 2回走査する方法

先に平均x̄を求め，次にΣ(xᵢ − x̄)²を求めれば，大きな値どうしの引き算を避けられる．
Chan，Golub，LeVequeの解析によれば，相対誤差は一次の近似でnu程度であり，κ_vにほとんどよらない．
ただし，データを2回読む必要がある．データが大きくて一度しか読めない場合や，データが順に届く場合には使えない．

## 4. Welfordの算法

Welfordの算法は，データを1回走査しながら，それまでのデータの平均mₖと偏差平方和Sₖを更新する．
k番目のデータxₖが来たとき，平均の更新式は次のとおりである．

```text
mₖ = mₖ₋₁ + (xₖ − mₖ₋₁)/k
```

偏差平方和の更新式は，Sₖ − Sₖ₋₁を展開すると得られる．

```text
Sₖ = Sₖ₋₁ + (xₖ − mₖ₋₁)(xₖ − mₖ)
```

2つの因子は，どちらもデータと平均の差なので，平均が大きくても小さな値どうしの積になる．
大きな値どうしの引き算は，xₖ − mₖ₋₁とxₖ − mₖの2か所だけで，その誤差は平均の計算誤差に由来する．

Chan，Golub，LeVequeは，相対誤差を一次の近似でnκ_v·u程度と見積もった．
主な誤差は，平均の計算の丸め誤差がkステップ目までにk·u·|x̄|程度たまり，それが偏差平方和の増分に掛かることから生じる．
誤差はκ_vに比例し，2乗にはならない．

この見積もりは厳密な不等式ではない．
このコースでは，見積もりに2倍の余裕を持たせたγ₂ₙ·κ_vを許容誤差にし，その根拠を誤差仕様書に書く．
条件数が1から10⁸までの3000組のデータで測った相対誤差は，最大で0.75nκ_v·uだった．
厳密な誤差界がないときは，見積もりの出典，余裕の大きさ，実測の値を記録しておくことが品質保証になる．

## 5. 厳密に成り立つ性質

Welfordの算法には，誤差の大きさによらず厳密に成り立つ性質が3つある．

### 結果は負にならない

k = 1ではm₁ = x₁で，増分は0である．
k ≥ 2では，d = fl(xₖ − mₖ₋₁)は正しい差と同じ符号を持つ(丸めは符号を変えない)．
更新した平均mₖ = fl(mₖ₋₁ + fl(d/k))について，|fl(d/k)|は|xₖ − mₖ₋₁|の半分程度なので，mₖ₋₁ + fl(d/k)はmₖ₋₁とxₖの間にある．
xₖは浮動小数点数なので，丸めの単調性から，丸めた結果mₖもxₖを越えない．
したがってdとxₖ − mₖは同じ符号を持ち，増分d(xₖ − mₖ)は0以上である．Sは減らないので，負にならない．

教科書の公式にはこの性質がない．

### 定数のデータの分散は0

すべてのxₖがcなら，m₁ = cで，以後はd = 0なので平均と偏差平方和は変わらない．結果は厳密に0である．

```julia
julia> variance(fill(1e8 + 0.1, 3)), textbook_variance(fill(1e8 + 0.1, 3))
(0.0, 2.0)
```

### 2の冪による拡大縮小

浮動小数点数に2ᵏを掛けると，指数が変わるだけで仮数は変わらない．
オーバーフローとアンダーフローが起きなければ，この掛け算は厳密である．
さらに，2ᵏ倍した数を含む四則演算の結果は，元の結果に対応する2の冪(足し算なら2ᵏ，2ᵏ倍どうしの掛け算なら2²ᵏ)を掛けた値と一致する．丸めの位置も同じだけ動くからである．

したがって，データを2ᵏ倍すると，Welfordの算法のすべての中間結果が2ᵏ倍(偏差平方和は4ᵏ倍)になり，結果は厳密に4ᵏ倍になる．

```julia
julia> variance(data .* 2.0^10) == variance(data) * 4.0^10
true
```

## 6. 性質ベーステスト

性質ベーステストは，個々の入力と期待値の組を並べる代わりに，「どんな入力についても成り立つ性質」を書き，たくさんの入力で確かめるテストである．
入力は乱数で作る．

```text
for seed in 1:50
    データ = 乱数(seed)で作る
    性質(データ)を確かめる
end
```

性質は，部分的な参照解として働く．
「分散は負にならない」という性質は，正しい分散を知らなくても検査できる．
その代わり，性質だけでは結果の値が正しいことまでは分からない．
このコースでは，参照解との比較(値の正しさ)と性質の検査(参照解のいらない保証)を組み合わせる．

性質には2種類ある．

- 厳密に成り立つ性質：負にならない，定数で0，2の冪で4ᵏ倍．`==`や`>=`で検査する．許容誤差がいらないので，最も強い検査になる．
- 許容誤差つきで成り立つ性質：平行移動，並べ替え．許容誤差を誤差界から導いて検査する．

## 7. メタモルフィックテスト

メタモルフィック関係とは，入力を変換したときに出力がどう変わるかの関係である．
分散には次の関係がある．

- 平行移動：すべてのデータにcを足しても，分散は変わらない．
- 並べ替え：データの順序を変えても，分散は変わらない．
- 拡大縮小：すべてのデータをa倍すると，分散はa²倍になる．

数学的な関係をそのまま浮動小数点数の検査に使うには，2つの点に注意する．

1つ目は，入力の変換そのものの丸めである．
x + cを浮動小数点数で計算すると丸めが入り，正しい分散そのものが変わってしまう．
模範解答では，整数値のデータに2の冪を足す．和が2⁵³より小さければ，足し算は厳密である．

2つ目は，比較の許容誤差である．
変換前と変換後の計算結果v̂₁，v̂₂は，どちらも正しい値vから許容誤差τ₁v，τ₂v以内にある．
したがって|v̂₁ − v̂₂| ≤ (τ₁ + τ₂)vで検査する．

メタモルフィックテストは，参照解がなくても間違った実装を見つけられる．
`variance`を教科書の公式に置き換えると，平行移動の検査は次のように失敗する．

```text
variance：メタモルフィック関係 seed = 1: Test Failed at …/test/unit/moments_tests.jl:60
  Expression: abs(variance(shifted) - variance(xs)) <= (tolerance(shifted) + tolerance(xs)) * exact
   Evaluated: 162.8041666665813 <= 0.0037065992312014895
```

## 8. テストデータの生成

性質ベーステストの価値は，入力の選び方で決まる．

- 条件数を制御する．平均center，標準偏差spreadの正規分布からデータを作ると，条件数はおよそ|center|/spreadになる．centerとspreadを10の冪の範囲から乱数で選び，条件数を1から10⁸まで広げる．
- 要素数も変える．n = 2のような小さいデータは，境界の誤りを見つけやすい．
- 誤差界の前提を守る．教科書の公式の検査では，κ_v²uが1を大きく超えると一次の近似が意味を持たないので，条件数を10⁴までに抑える．

## 9. 再現性

乱数を使うテストは，失敗したときに同じ入力を再現できなければ調べられない．

- 乱数生成器にシードを与えて作る(`Xoshiro(seed)`)．同じシードからは，同じ乱数列が得られる．
- テストごとにシードを決め，`@testset`の名前にシードを含める．失敗したとき，表示された名前からシードが分かる．
- グローバルな乱数生成器(`rand()`をシードなしで呼ぶもの)を使わない．ほかのテストが乱数を使うと，乱数列が変わってしまう．

```julia
julia> rng = Xoshiro(42); rand(rng, 3)
3-element Vector{Float64}:
 0.6293451231426089
 0.4503389405961936
 0.47740714343281776
```

同じシードで何度作っても，同じ3つの値になる．

## 10. 許容誤差の計算の丸め

許容誤差そのものも浮動小数点数で計算する．
例えば平均の誤差界(1 + β)(1 + u) − 1(βは補償付き総和の誤差界，uは割り算の丸め)を，この式のまま計算すると，1 + uが1に丸められて0になる．
正しい実装でも「誤差 ≤ 0」は成り立たないので，テストは不合格になる．

式を展開して，β + u + βuと計算すれば，1との足し算が現れず，丸めで消える項がない．
誤差界の式は，計算する前に，1との足し算や近い値の引き算が現れない形に変形する．
