# Iteration 6：関数を渡す関数と型に依存しない関数

Iteration 6で初めて使うJuliaの文法と機能をまとめる．

## 関数を引数として渡す

Juliaでは，関数もほかの値と同じように引数として渡せる．
関数を受け取る関数を高階関数と呼ぶ．

```julia
julia> apply_twice(h, x) = h(h(x));

julia> apply_twice(x -> x^2, 3)
81
```

`integrate(step, f, t0, y0, t_end, n)`は，1ステップの方法`step`と右辺`f`の2つの関数を受け取る．
`step`に`euler_step`を渡すか`rk4_step`を渡すかで，同じ`integrate`が違う方法になる．

## 匿名関数

`(t, y) -> 式`は，名前のない関数(匿名関数)を作る．
その場でしか使わない右辺を渡すのに便利である．

```julia
julia> g = (t, y) -> -2y;

julia> euler_step(g, 0.0, [1.0], 0.1)
1-element Vector{Float64}:
 0.8
```

`function`や`名前(引数) = 式`で定義した関数と同じように呼べる．
テストでは，`rk4_step((t, y) -> [4t^3], 0.0, [0.0], 1.0)`のように，確かめたい右辺をその場で書く．

## 型に依存しない関数

`euler_step`や`integrate`の引数には型注釈を付けていない．
`y + h * f(t, y)`のような式は，yの要素の型(`Float64`や`BigFloat`)の演算で計算される．

```julia
julia> integrate(rk4_step, g, big(0.0), [big(1.0)], big(1.0), 10)
1-element Vector{BigFloat}:
 0.135339548430510116620208891634063409233992487595048180324814984165692899117681
```

数値の定数を書くときは，型を変えてしまわないように注意する．

- `h / 2`，`h / 6`のように整数で割るのは，hの型のまま計算される．
- `0.5 * h`と書くと，hが`BigFloat`でも`0.5`は`Float64`の定数である．0.5は2進数で厳密に表せるので結果は変わらないが，`0.1 * h`のように表せない定数を書くと，`BigFloat`で計算しても`Float64`の精度の誤差が入る．
- 初期値の時刻は`zero(T)`，2は`T(2)`のように，型Tに合わせて作る．

`BigFloat`で計算する精度は，`setprecision(BigFloat, 128) do ... end`でブロックの中だけ変えられる(Iteration 1)．
収束次数の検査では，`Float64`より十分高い128ビットで実行する．

## 2の冪の計算

pが整数なら，`2^p`は整数で計算される．`(y_coarse - y_fine) / (2^p - 1)`のように，整数で割ると浮動小数点数になる．
`log2(x)`は2を底とする対数である．比が2の冪なら，結果は厳密に整数になる．
